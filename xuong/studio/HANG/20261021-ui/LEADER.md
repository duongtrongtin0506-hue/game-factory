# LEADER – Game UI Kit Bundle

Leader: gói CC0 của Kenney (kenney.nl – nguồn asset miễn phí được tải nhiều nhất cho game indie) và các gói CC0 nổi bật trên OpenGameArt.

| # | Đặc điểm gói leader | Gói mình |
|---|---|---|
| 1 | PNG từng hình | ✅ PNG/ |
| 2 | Spritesheet | ✅ spritesheet.png |
| 3 | Tệp tọa độ (XML) | ✅ JSON atlas dạng TexturePacker (Phaser/PixiJS đọc thẳng) |
| 4 | Ảnh xem trước | ✅ 5 ảnh + GIF |
| 5 | Giấy phép CC0 rõ | ✅ LICENSE.txt + CREDITS.md |
| 6 | Tên tệp có quy luật | ✅ <chu-de>_<goi>_<so>_<ten>.png |
| 7 | Trang xem toàn bộ | ✅ preview.html có ô tìm |
| 8 | Demo | ✅ demo.html chạy được |

Giá trị thêm so với tải lẻ: gom 3 gói cùng chủ đề vào 1 bộ, 1 atlas chung, đặt tên thống nhất, trang tìm kiếm, demo.
